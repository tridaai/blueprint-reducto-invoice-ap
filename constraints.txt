# Frozen dependency set for this blueprint — Python 3.10–3.12, macOS/Linux.
#
# Why this file exists: with loose >= ranges, `pip install -e ".[dev]"` on
# Python 3.10 backtracked effectively forever. The trigger was transitive:
# langchain-core -> langsmith requires websockets>=15.0 (unbounded), and
# websockets 17.x requires Python >=3.11, so on 3.10 pip kept unwinding and
# re-resolving langgraph / langchain-core / pydantic / uvicorn / pytest.
#
# This is the known-good set resolved on Python 3.12, with websockets held
# at 16.0 (newest line supporting 3.10). Every version below supports both
# 3.10 and 3.12. Install with:
#
#     pip install -r constraints.txt
#     pip install --no-deps -e .
#
# (the two-step form in the Makefile — pip refuses an editable install
# under a hashed constraints file, so the frozen set and the package
# itself are installed in separate steps).
#
